# Build notes: feedback-induced bistability and global state selection

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, hyperref, graphicx). Author,
  affiliation and date are the three `\newcommand` macros at the top of the
  file (`\PaperAuthor`, `\PaperAffiliation`, `\PaperDate`); they are
  placeholders and must be set before submission.
- `refs.bib` — bibliography (plain style; DOI links are carried in `note`
  fields because `plain.bst` does not print `doi`).
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/` — `network.pdf` (schematic, from `scripts/network_schematic.py`),
  `feedback.pdf`, `basins.pdf`, `traces.pdf` (from `scripts/figures.py`).
- `scripts/` — exact certificates and figure generators (see below).
- `data/` — certificate outputs and saved figure data, plus the strict Lean
  receipt `Main.declaration.verify.2026-09-13.json`.

Compiled output is copied to `..\Feedback_Bistability_Global_Selection.pdf`.

## Reproducing certificates and figures

From this folder, with a Python that has SymPy (certificates) and NumPy,
SciPy, Matplotlib (figures):

```powershell
python scripts/check_principal_algebra.py      # also runs certify_fold.py -> data/fold_certificate.json, data/principal_algebra.json
python scripts/check_spectra_and_table.py      # Bernstein spectral bounds + Table 3 -> data/spectral_and_table_check.json
python scripts/network_schematic.py            # figures/network.pdf
python scripts/figures.py                      # figures/feedback.pdf, basins.pdf, traces.pdf, data/*.npz, continuation.csv, figure_summary.json
```

All acceptance tests in the certificate scripts use exact rational
arithmetic (Python fractions / SymPy rationals). The figure script is
illustrative only.

## Provenance

The paper consolidates two workspace manuscripts:

- `problem_workspaces/RAF_core_coupling_multistationarity/followup/manuscript.tex`
  (feedback/global-selection manuscript; organizing source) with its
  `scripts/`, `data/` and `figures/`, copied here verbatim;
- `problem_workspaces/RAF_core_coupling_cac/paper/manuscript.md`
  (core-coupling CAC manuscript; literal model, clamped uniqueness,
  reconstruction, Descartes count, local certificates).

Independent re-checks performed while drafting (2026-09-13): the SymPy
script in the session scratchpad verified the response branch, the exact
residual equations, all three partial derivatives of the potential, the
absorbing-region identities, the Jacobian, the activity identities, the
general-rate and routed reconstructions and balances, the cleared
polynomial (7), the Descartes coefficient table, and the routed determinant
identity; `check_spectra_and_table.py` re-derived the Bernstein spectral
bounds (the bound at lambda = 1/10 is 55, sharper than the 44 quoted in the
workspace manuscript) and the equilibrium table; `certify_fold.py` was
re-run (PASS, contraction norm 1.0968e-7).

Material deliberately left for a supplement: the campaign chronology and
hypothesis ledger, the Lean module-by-module theorem index of
`CoreCouplingGlobal` (about 140 modules), the failed approaches recorded in
the workspace checkpoints, and the general-rate robustness discussion of
the CAC manuscript beyond Proposition 6.1.
