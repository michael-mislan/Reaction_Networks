# Thermodynamic compatibility of interacting autocatalytic cores: an exact phase diagram and a layered obstruction theory

[Read the paper](../../../Theory/Thermodynamics/P009-interacting-core-thermodynamics.pdf) · [Claim map](claims.json) · [Build instructions](../../BUILD.md) · [All papers](../../../README.md)

A potential autocatalytic core (PAC) is a minimal stoichiometric motif that admits a strictly productive reaction current; a consistent autocatalytic core (CAC) is a PAC whose productive current is realized by a positive concentration vector under thermodynamically consistent mass-action kinetics.
