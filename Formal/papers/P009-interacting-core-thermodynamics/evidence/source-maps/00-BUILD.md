# Build notes: thermodynamic compatibility of interacting autocatalytic cores

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, TikZ figures, listings for
  Lean snippets, natbib + hyperref). Author, affiliation and date are the
  three `\newcommand` macros at the top of the file.
- `refs.bib` — bibliography (`unsrtnat` style, numeric, citation order).
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.

Compiled output is copied to `..\Thermodynamic_Compatibility_Autocatalytic_Cores.pdf`.

All figures are drawn in TikZ inside `main.tex`; there are no external
graphics files. The earlier ReportLab-rendered drafts and their SVG/PDF
figures remain in
`problem_workspaces\RAF_thermo_core_compatibility\publication\` and are not
used here.

## Compiling (MiKTeX, user scope, not on PATH)

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

Page previews for visual QA can be rendered with the Poppler bundled in the
Codex runtime:

```powershell
& "$env:USERPROFILE\.cache\codex-runtimes\codex-primary-runtime\dependencies\native\poppler\Library\bin\pdftoppm.exe" -png -r 80 main.pdf preview\p
```

## arXiv submission

Upload `main.tex`, `refs.bib` and `main.bbl` (arXiv runs pdflatex itself and
will use the `.bbl`). Set the author macros first. Suggested categories:
q-bio.MN (primary), math.OC or math.AG (cross-list), cs.LO for the formal
verification component.
