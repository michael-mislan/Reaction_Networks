\section{Parent closed-RAF certificates}
Constructive activation checks both reactants and the positive catalyst formula against the current prefix pool. In each parent instance, the terminal activated set equals the maxRAF as a set of direction identifiers. There are 23 synchronous activation layers. The respective pruning sequences are $9231,2823,2148,2148$ and $9227,2584,2085,2085$.

The machine-readable activation orders, molecule birth ranks, producing-direction witnesses and ambient sets are in \texttt{postproof\_pilot.json}. They can be regenerated by \texttt{postproof\_pilot.py}. The Lean certificates encode the finite sets by bit masks, ranks and producer indices by bit planes, and source access by blocks of 128 directions. This representation is an implementation of the same finite checks; it does not change the reaction model. The generic checker proves that activation forces every selected reaction into every closed RAF. Two upper-pool checks bound every RAF by the selected set. A final support check proves that set is itself closed.
