# Build notes: unistationarity of Type II_l and Type V cores with nonnegative degradation

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, hyperref, listings for the
  Lean declaration). Author, affiliation and date are the three `\newcommand`
  macros at the top of the file (`\PaperAuthor`, `\PaperAffiliation`,
  `\PaperDate`); author and affiliation are deliberately blank.
- `refs.bib` — bibliography (plain style; DOI links are carried in `note`
  fields because `plain.bst` does not print `doi`). The companion
  positive-degradation Type II_l paper is the deliberately author-less entry
  `TypeIIpos` (sorted under the `key` field).
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/normal_forms.pdf`, `figures/admissibility.pdf` — vector figures,
  produced by `experiments/publication_figures.py` in the campaign workspace
  (see Provenance).

Compiled output is copied to `..\Unistationarity_Nonnegative_Degradation_TypeII_TypeV.pdf`.

## Compiling (MiKTeX, user scope, not on PATH)

Compile in a fresh directory: on this machine MiKTeX has intermittently
failed to overwrite existing `.aux`/`.log` files in place (truncated logs,
spurious "Undefined control sequence" at end of run). Copy `main.tex`,
`refs.bib` and `figures/` to a scratch folder, then:

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

The last build (2026-09-14) produced 20 pages with no overfull or underfull
boxes, no undefined references and no undefined citations. The only BibTeX
warning is the empty author of the companion-manuscript entry.

## Editing notes

- Lean identifiers are typeset with `\lean{...}` (defined through the `url`
  package), so they break at underscores and dots. Write underscores
  literally inside `\lean{}`. Do not use `\lean{}` inside captions or other
  moving arguments; use `\texttt{...\_...}` there.
- The terminal Lean declaration in Section 9 is a `lstlisting` in the `Lean`
  language with `literate` replacements for the Unicode symbols
  (forall, arrow, wedge, blackboard N); the `.tex` file is UTF-8.
- Section titles containing math use `\texorpdfstring`.
- The module table is a `[H]` float so that it stays in Section 9.
