# Build notes: attracting oscillations in sequential distributive multisite phosphorylation

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, one TikZ
  figure and five included PDF figures). Author, affiliation and date are the
  `\newcommand` macros at the top (`\PaperAuthor`, `\PaperAffiliation`,
  `\PaperDate`); author and affiliation are deliberately blank. Lean identifiers
  are typeset with the breakable `\lean{...}` command (do not use it in captions).
- `refs.bib` — bibliography (`plainnat`, numeric, 46 entries, all checked against
  Crossref/arXiv on 17 September 2026). DOIs are `\href` links in `note` fields.
  The `@unpublished` entry `CompanionCores` (key `Companion`, empty author) is the
  companion child-selection manuscript; its BibTeX "empty author" warning is deliberate.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/*.pdf` — produced by `make_figures.py` from `figures/numerical_data.json`
  (`make_data.py`, about 10 minutes), `figures/region_data.json` (`make_region.py`,
  about 3 minutes), `certificates/paper_certificates.json` (`check_paper.py`) and
  `workspace_certificates/measurement_practical_certificate.json`.
- `phos.py` — exact n-site model builder from the reaction list and the interval
  Hopf certifier (Sturm/Routh/interval eigenvectors/first Lyapunov coefficient,
  C2 reduction, sensitivities, resonance constants). Independent of the workspace
  code except for `interval_arithmetic.py` (copied from the workspace).
- `check_paper.py` — replays every certified number of the paper (86 checks, under
  a minute; `--quick` skips the five/six-site witnesses and the pulse flow) and
  writes `certificates/paper_certificates.json`. Last run 17 September 2026: all passed.
- `validate_orbit.py` — computer-assisted proof of the finite-amplitude orbits at
  r = 7/5 and r = 1 (multiple shooting + Newton–Kantorovich, binary64 interval arithmetic with
  outward rounding, Floquet multipliers by Gershgorin in a floating-point frame).
  `python validate_orbit.py 7/5` takes about fourteen minutes and writes
  `certificates/orbit_certificate_7_5.json` (and the interval blocks `.npz`); `python validate_orbit.py 1` takes about 32 minutes and writes `orbit_certificate_1.json`.
- `numerics.py`, `make_data.py`, `make_region.py` — floating-point (N) material only.
- `workspace_certificates/` — the original certificate programs and their JSON
  outputs from `problem_workspaces/RAF_phosphorylation_generalized_oscillation_beer_game`
  (block-formula Jacobian, validated Taylor pulse flow, resource constants).

Build (MiKTeX, `%LOCALAPPDATA%\Programs\MiKTeX\miktex\bin\x64` on PATH):

```
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

Python: the repository's `.venv` (Python 3.11, SymPy 1.14, NumPy 2.4, SciPy 1.17,
Matplotlib 3.11). Run the scripts from this folder.

Compiled output is copied to
`..\Attracting_Oscillations_Distributive_Multisite_Phosphorylation.pdf`.

Evidence split (also stated in the paper): the attraction theorem, the all-n
theorem and everything about witness A are conventional proofs with exact-rational
interval certificates (C+I); only `ThreeSitePhosphorylation.three_site_hopf_capacity`
(existence at the subcritical witness H) and two small algebraic lemmas are Lean.
The finite-amplitude orbit certificate uses binary64 intervals, not rationals.
