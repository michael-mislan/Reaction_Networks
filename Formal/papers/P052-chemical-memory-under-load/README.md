# Chemical Memory under Load: Productive Inheritance and Hidden Operating States

[Read the paper](../../../Theory/Memory/P052-chemical-memory-under-load.pdf) · [Claim map](claims.json) · [Build instructions](../../BUILD.md) · [All papers](../../../README.md)

Can a chemical state be inherited while the species supporting its reproduction is continuously extracted, and which observations reveal the productive state under feedback? We answer these questions for two operating arrangements of one four-species resident chemistry.

The full abstract, hypotheses and numbered results are in the manuscript.
