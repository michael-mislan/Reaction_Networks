# Global production optima and the sharp positive-response capacity of autocatalytic networks

[Read the paper](../../../Theory/Production/P022-global-production-optima.pdf) · [Claim map](claims.json) · [Build instructions](../../BUILD.md) · [All papers](../../../README.md)

For a tightly coupled mass-action autocatalytic network whose stationary production of a controlled species is maximal, the affinity of the overall reaction is determined by the first-order response of the one-way fluxes to the control.
