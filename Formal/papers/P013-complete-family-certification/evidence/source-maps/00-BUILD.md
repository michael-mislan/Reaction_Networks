# Build notes: Complete irreducible autocatalytic families paper

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, tikz, hyperref). Author,
  affiliation and date are the three `\newcommand` macros at the top of the
  file (`\PaperAuthor`, `\PaperAffiliation`, `\PaperDate`).
- `refs.bib` — bibliography (plain style; DOIs are carried in the `note`
  field as `\href` links because `plain.bst` prints no `doi` field).
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `brute_check.py` — independent brute-force check (literal subset
  enumeration under the RAF definition) of Examples 2.6 and 4.3 and of the
  census figures quoted in Section 8.2. Run with any Python 3; takes ~3 s.
- `PUBLICATION_HANDOFF.md` — what is proved, what was checked, what remains.

Compiled output is copied to `..\Complete_Irreducible_Autocatalytic_Families.pdf`.

## Compiling (MiKTeX, user scope, not on PATH)

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

## arXiv submission

Upload `main.tex`, `refs.bib` and `main.bbl` (arXiv runs pdflatex itself and
uses the `.bbl`). No figures (the one figure is TikZ) or custom style files
are required. Set the author macros first; the companion Min-RAF paper is
cited as `minraf2026` in `refs.bib` with an `Anonymous` author placeholder that
should be replaced at the same time.
