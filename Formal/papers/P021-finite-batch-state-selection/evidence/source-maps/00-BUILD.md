# Build notes: finite-batch selection under a shared limiting resource

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, three
  included PDF figures). Author, affiliation and date are the `\newcommand`
  macros at the top of the file (`\PaperAuthor`, `\PaperAffiliation`,
  `\PaperDate`); author and affiliation are deliberately blank in this
  version. Long Lean identifiers are typeset with the breakable `\lean{...}`
  command (a `url`-style command); do not use it inside math or in captions.
- `refs.bib` — bibliography (`plainnat`, numeric, 31 entries). All entries are
  primary literature or standard references; DOIs are printed by `plainnat`.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/model.pdf`, `figures/bounds.pdf`, `figures/consequences.pdf` —
  vector figures produced by `make_figures.py` (Matplotlib + SciPy). They
  evaluate proved formulas; nothing is simulated.
- `check_constants.py` — independent check (`py check_constants.py`; needs
  mpmath and numpy). Verifies in exact rational arithmetic every constant
  relation used in the proofs (eq. (5), the sharper-envelope margins, the
  spatial/reset/partition slacks, the affine budget at the source threshold,
  the population-tail margins, the root sign changes and the drift identity on
  the stationary curve, the energy matrices against the Lean coefficient
  lists, the two-founder 4/7 minimum), the frequency examples, and the
  directed-interval entries of Table 2. Last run (14 September 2026):
  ALL CHECKS PASSED.

Compiled output is copied to
`..\Finite_Batch_Selection_Inherited_Chemical_States.pdf`
(21 pages, 14 September 2026). The last MiKTeX build had no errors, no
overfull/underfull boxes and no undefined references, citations or hyperref
warnings; every page was rendered and inspected.

## Compiling (MiKTeX, user scope, not on PATH)

Build in a fresh scratch directory (in-place builds on this machine have
produced spurious end-of-run errors before):

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
py make_figures.py
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

Page previews for visual QA: `pdftoppm -r 70 -png main.pdf render/p`
(pdftoppm ships with MiKTeX).
