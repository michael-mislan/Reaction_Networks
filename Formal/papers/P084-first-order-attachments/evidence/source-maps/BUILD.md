# Build notes: D-stability under first-order attachments at a single coordinate

arXiv-ready source for *D-stability under first-order attachments at a single coordinate: an exact static threshold and a subset-sum criterion* (September 2026). Earlier working title (used in
`qa/REFEREE_REPORT.md`): "Lumps, fragments, and D-stability". The PDF is copied to
`..\D_Stability_First_Order_Attachments_Single_Coordinate.pdf`.

Supersedes the 11-page workspace draft
`problem_workspaces/RAF_D_stability_characterization/Granularity_and_Coordinate_Interfaces.tex`
(title changed to name D-stability; the draft is left untouched).

## What changed relative to the draft

- **New exact theorem (Thm 8.3, Cor 8.4).** For the family B(h) the subset-sum
  test is exact for every partition: A_r is D-stable iff no subset sum lies in
  the static window (h0-h+, h0-h-). At total 2 on B(6): D-stable iff the
  largest piece is >= 6-h- = (7963+329*sqrt(409))/7780 = 1.878742...
  So (19/10,1/10) and (47/25,3/25) are stable; (15/8,1/8) and (1,1) are not.
  It rests on Lemma 8.2, an exact certificate that every one-attachment edge
  between D-stable corners is D-stable (702 coefficient polynomials in (H,J),
  classified and certified in `check_paper.py`).
- **New general results:** subset-sum obstruction (Prop 6.2, Hurwitz's
  theorem); merging is safe / lump most protective (Cor 6.3); edge-and-corner
  reduction (Lemma 6.1); disk form of the fixed-partition test (Cor 5.3);
  bounded time-scale spread raises the threshold (Prop 4.5, proved: the
  supplement's sketch is now a full compactness proof, incl. the tau = 0 case);
  uniform spread of the fine-partition witnesses (Lemma 4.2(b)); NI-module
  corollary of the hub theorem (Cor 9.4).
- **Repairs:** Lemma 4.2's y>0 step is written out (the draft's eps bound is
  kept but halved to give partition-independent bounds); Theorem 5.2's base
  point is now a self-contained determinant argument; Theorem 9.1's
  multiaffine propagation is expanded; Prop 7.1 uses Prop 6.2 for the
  persistence step; Prop 8.1's instability step uses Orlando's formula;
  Section 2.3 gives the three-step physical normalization.
- **Bibliography:** 35 references, each checked against Crossref/arXiv/publisher
  pages on 2026-09-27 (`qa/REFERENCES_VERIFICATION.txt`). Unverified details:
  Cain (1976) end page, and the Petersen–Lanzon (2010) author list; Crossref
  lacks both, and the values used follow standard citations.

## Source files

- `main.tex` — the paper (24 pages). Author/affiliation macros `\PaperAuthor`,
  `\PaperAffiliation` are deliberately blank (repository convention).
- `refs.bib`, `main.bbl` (BibTeX style `plainurl`, prints DOIs/arXiv ids).
- `figures/loading_window.pdf`, `figures/protection_envelopes.pdf` —
  regenerated by `make_figures.py` (Figure 3's core envelope is a sampled
  numerical lower estimate, labelled as such). Figure 1 is TikZ in `main.tex`.
- `check_paper.py` — exact replay of every printed number and of the Lemma 8.2
  certificate; prints `43/43 checks passed` (~90 s) and writes
  `check_results.json`. `[num]` checks are floating-point sanity checks only.
- `make_manifest.py` → `ARTIFACT_MANIFEST.json` (formal root, receipt, axioms,
  SHA-256 of Lean sources, scripts, figures, base git revision).
- `qa/` — rendered page images, visual review, reference verification report,
  independent referee report (`REFEREE_REPORT.md`) and point-by-point responses (`REFEREE_RESPONSE.md`).

## Editing pitfalls

- Never write LaTeX through Git-Bash heredocs: `\\` collapses to `\` (happened
  once in this build and was caught by `qa` scanning). Use the Edit tool or
  Python scripts saved as files.
- `plainurl` needs `url`/`hyperref`; do not add `cleveref`.
- Keep the core-envelope symbol `\Core` (Θ) distinct from inverse rates `Q`.
