# D-stability under first-order attachments at a single coordinate: an exact static threshold and a subset-sum criterion

[Read the paper](../../../Theory/D-Stability/P084-first-order-attachments.pdf) · [Manuscript](manuscript/main.tex) · [Claim map](claims.json) · [Build instructions](../../BUILD.md)

Positive first-order attachments at one coordinate have an exact static D-stability threshold. Partition geometry distinguishes stable and unstable load splits and yields a subset-sum criterion for the studied four-state family.

**Formalization:** The central threshold theorem and its supporting matrix arguments are formalized. The subset-sum criterion, fixed-partition geometry, and further extensions use conventional proofs and exact computational certificates as identified in the paper.
