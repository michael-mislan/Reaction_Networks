# Build notes: child-selection determinants and unstable cores in futile cycles

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, four
  included PDF figures). Author, affiliation and date are the `\newcommand`
  macros at the top of the file (`\PaperAuthor`, `\PaperAffiliation`,
  `\PaperDate`); author and affiliation are deliberately blank in this
  version. Long Lean identifiers are typeset with the breakable `\lean{...}`
  command (a `url`-style command); do not use it inside math or in captions
  (use `\texttt{}` there). Underscores inside `\lean{}` are written literally.
- `refs.bib` — bibliography (`plainnat`, numeric, 31 entries). DOIs are
  carried in `note` fields as `\href` links. The two `@unpublished` entries
  with key `Companion` are the earlier D-core manuscripts of this project
  (their BibTeX "empty author" warnings are deliberate).
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/source_network.pdf`, `figures/positive_flower.pdf`,
  `figures/alpha_decay.pdf`, `figures/spectra.pdf` — vector figures produced
  by `make_figures.py` (Matplotlib + SciPy) from proved formulas and from the
  illustrative eigenvalue lists in `exact_certificates.json`.
- `check_paper.py` — independent exact replay (SymPy) of every constant in
  the paper: the source network, the matrices A_-, B, BD_*, Q, the
  characteristic polynomials, all Routh columns and sign counts, the
  reciprocal-root and logarithmic-derivative certificates, both explicit
  eigenvectors, the Lyapunov identity and minors, the positive family
  (dimension, sign conjugacy, determinant, characteristic polynomial and
  flower eigenvector for n <= 8), the identification A_2 = S_2 and the
  reconstruction of the Vassena–Stadler matrices S_1, S_2, S_3, the n = 10
  Routh signs, the alpha_n table with Lambert brackets, the kinetic model
  (balanced flux, derivative identity, q_J, conservation laws, rank), and the
  numerical eigenvalues quoted in the text. `py check_paper.py --census`
  additionally replays the n = 2 (4455 children, ~4 s) and n = 3 (204849
  children, ~5 min) exhaustive determinant censuses and the floating-point
  unstable-core screen quoted in Section 9. Last run (14 September 2026):
  ALL CHECKS PASSED (with and without `--census`).
- `exact_certificates.json` — the certificate file produced by the workspace
  script `publication/postproof_checks.py`; used only by `make_figures.py`.

Compiled output is copied to
`..\Futile_Cycle_Child_Selection_Determinants_Unstable_Cores.pdf`
(22 pages, 14 September 2026). The last MiKTeX build had no errors, no

## Compiling (MiKTeX, user scope, not on PATH)

Build in a fresh scratch directory (in-place builds on this machine have
produced spurious end-of-run errors before):

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
py make_figures.py
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

If `make_figures.py` aborts with an OpenBLAS allocation error, set
`$env:OPENBLAS_NUM_THREADS = "1"` first. The repository interpreter
`.venv\Scripts\python.exe` has all required packages.

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

Page previews for visual QA: `py` with PyMuPDF (`fitz`), see the session
notes, or `pdftoppm -r 70 -png main.pdf render/p` (ships with MiKTeX).
