# Build notes: elementary cores, abundant reactions, and the union-closed boundary

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, two TikZ
  figures drawn inline). Author, affiliation and date are the three
  `\newcommand` macros at the top of the file (`\PaperAuthor`,
  `\PaperAffiliation`, `\PaperDate`). Long Lean identifiers are typeset with
  the breakable `\lean{...}` command (a `url`-style command); identifiers that
  contain spaces use plain `\texttt{...}`.
- `refs.bib` — bibliography (`plainnat` style, numeric). DOIs are in `doi`
  fields and are printed by `plainnat`.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `check_examples.py` — standard-library Python script that enumerates the RAF
  families of Examples 5.2, 5.8, 5.10, 5.11 and 6.3 exhaustively and asserts
  the numbers printed in the paper (fibres, slacks, frequencies, defect bound).

Compiled output is copied to
`..\Elementary_Cores_Abundance_Realizability_RAF.pdf` (20 pages).
