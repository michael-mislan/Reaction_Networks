# Elementary cores, abundant reactions, and the union-closed boundary of autocatalytic reaction systems

[Read the paper](../../../Theory/Structural/P020-elementary-cores-union-closed.pdf) · [Claim map](claims.json) · [Build instructions](../../BUILD.md) · [All papers](../../../README.md)

A reflexively autocatalytic and food-generated set (RAF) of a catalytic reaction system is a collection of reactions that can be built up from a food set and in which every reaction is catalysed from within.

The full abstract, hypotheses and numbered results are in the manuscript.
