# Build notes: abundant reactions with locally ranked supplier cores

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, three
  figures drawn inline with TikZ/pgfplots; no external image files). Author,
  affiliation and date are the `\newcommand` macros at the top of the file
  (`\PaperAuthor`, `\PaperAffiliation`, `\PaperDate`); the first two are blank
  deliberately. `\CompanionAuthor` (currently "Anonymous") fills the author
  field of the companion-manuscript and repository citations in `refs.bib`
  because BibTeX needs a non-empty author to sort. Long Lean identifiers are
  typeset with the breakable `\lean{...}` command (a `url`-style command);
  identifiers containing spaces use plain `\texttt{...}`.
- `refs.bib` — bibliography (`plainnat` style, numeric). DOIs are in `doi`
  fields and are printed by `plainnat`. All non-companion entries are the
  DOI-checked set shared with the elementary-cores paper, plus
  `steel2013minimal` from the supplier-bounded enumeration paper.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `check_paper.py` — standard-library Python script that replays every finite
  number printed in the paper by exhaustive food-closure enumeration (strict
  example, three-chain family for 3 ≤ ℓ ≤ 5, all-or-none modules, the
  twelve-reaction frequency table and deletion panel, the conservation lift,
  the bounded-distortion sharpness example, and Proposition 2.3 on random
  systems). It performs no Lean compilation.
- `build.ps1` — runs the check script, then pdflatex/bibtex/pdflatex/pdflatex
  and copies the PDF one level up.

Compiled output is copied to
`..\Locally_Ranked_Supplier_Cores_Abundant_Reactions.pdf` (19 pages).

## Compiling (MiKTeX, user scope, not on PATH)

```powershell
.\build.ps1
```

or by hand:

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

The last MiKTeX build had no errors, no undefined references and no overfull
boxes. Page previews for visual QA: `pdftoppm -r 70 -png main.pdf page`
(pdftoppm ships with MiKTeX).
