# Build notes: overlapping siphons, resident-dependent invasion, uniform permanence

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, one
  included PDF figure). Author, affiliation and date are the `\newcommand`
  macros at the top of the file (`\PaperAuthor`, `\PaperAffiliation`,
  `\PaperDate`); author and affiliation are deliberately blank in this
  version. Long Lean identifiers are typeset with the breakable `\lean{...}`
  command (a `url`-style command); do not use it in captions.
- `refs.bib` — bibliography (`plainnat`, numeric). DOIs are printed by
  `plainnat`.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/proof_structure.pdf` — the single vector figure, produced by
  `make_figures.py` (Matplotlib, deterministic, no simulation). It is a copy
  of the campaign workspace figure `paper_assets/proof_structure.pdf`.

Compiled output is copied to
`..\Overlapping_Siphons_Resident_Invasion_Uniform_Permanence.pdf`
(20 pages, 14 September 2026). The last MiKTeX build had no errors, no
overfull/underfull boxes and no undefined references or citations; every
page was rendered and inspected.
