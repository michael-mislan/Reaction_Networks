# Build notes: an exact oscillatory instability in a minimal Type II autocatalytic core with linear degradation

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, hyperref, listings for the
  two Lean declarations, TikZ for the network figure; 20 pages). Author,
  affiliation and date are the three `\newcommand` macros at the top of the
  file (`\PaperAuthor`, `\PaperAffiliation`, `\PaperDate`); author and
  affiliation are deliberately blank and must be set before submission.
- `refs.bib` — bibliography (plain style; DOI links are carried in `note`
  fields because `plain.bst` does not print `doi`). The two companion
  manuscripts (`TypeIIpos`, `TypeIImixed`) are deliberately author-less
  `@unpublished` entries sorted by their `key` fields; BibTeX warns about
  them.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/spectrum.pdf` — the only external figure (numerical spectrum of
  the Jacobian and the exact linearised mode), regenerated by
  `make_figures.py` (NumPy, Matplotlib). The network diagram of Figure 1 is
  inline TikZ.
- `check_paper.py` — exact re-verification (fractions, SymPy for the
  symbolic derivative and the transfer formula) of every number printed in
  the paper: the split graph and the 126-subset minimality enumeration, the
  autocatalytic flux, the unit-return-cycle production bound, positivity of
  the 28 integers and of the 21 rate constants, the stationary balance,
  agreement of the integer tables with the rational LP vertex stored in the
  workspace (`exact_eigenpair_design.json`), both pencil identities and the
  coordinate table, the exact complex eigen-equation, `DF(x) = H X^{-1}`,
  the frequency-dependent return response (6.2), and the numerical
  observations quoted in Sections 5–6 (remaining spectrum, `H` Hurwitz,
  stationary Schur complement Hurwitz, corner frequency 6.123). It prints
  `All 27 checks passed.` and also prints the approximate rate table of
  Table 3.
- `main.pdf` — compiled output; also copied to
  `..\Oscillatory_Instability_Minimal_TypeII_Core_Degradation.pdf`.

## Compiling (MiKTeX, user scope, not on PATH)

Compile in a fresh directory (copy `main.tex`, `refs.bib` and `figures/`):

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```


## Editing notes

- Lean identifiers are typeset with `\lean{...}` (url package,
  `\DeclareUrlCommand`), so they break at underscores and dots. Write
  underscores literally inside `\lean{}`. Never use `\lean{}` inside math
  mode or inside a caption; use `\texttt{}` there.
- The two Lean declarations in Section 7 are `lstlisting` blocks in the
  `Lean` language with `literate` replacements for the Unicode symbols; the
  `.tex` file is UTF-8.
- `\Re` is `\renewcommand`ed (amsmath already defines it); `\Im` likewise.
- Species and reactions are indexed from 0, as in the Lean sources and the
  workspace handoff; the companion papers index from 1.
- Theorem numbers quoted from the companion nonnegative-degradation paper
  were read from its compiled PDF
  (`..\Unistationarity_Nonnegative_Degradation_TypeII_TypeV.pdf`): Theorem
  1.1, Lemma 2.4 (unit return paths), Lemma 6.1 (invertible source
  matrix), Theorem 6.5 (boundary nonsingularity), Proposition 8.4 (small
  degradation), Proposition 8.5 (origin or positive). NNU Theorems 3.1,
  4.1 and 5.2 are quoted as in the companions.
- Perko is cited by chapter, Horn–Johnson by appendix (D, continuity of
  eigenvalues), Kuznetsov without section numbers.
