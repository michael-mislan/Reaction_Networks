# Build notes: finite-resource amplification can eliminate diagnostic readout windows

Source files in this folder:

- `main.tex` — the paper (article class, amsthm, natbib + hyperref, five
  included PDF figures, six tables, a claims-to-declarations map in
  Appendix E). Author, affiliation and date are the `\newcommand` macros at
  the top of the file (`\PaperAuthor`, `\PaperAffiliation`, `\PaperDate`);
  author and affiliation are deliberately blank in this version.
  `\RepositoryNote` is the sentence printed under "Reproducibility"; replace
  it by the public repository location. The numbers of the h = 1e8 stress
  test (Table 3) are the macros `\tplus`, `\tminus`, `\muplus`, `\muminus`,
  `\BigBlankTwo`, `\BigMissTwo`, `\BigBlankOne`, `\BigMissOne`, `\BigTbTwo`,
  `\BigTbOne`, `\BigBoundaryTwo`, `\BigBoundaryOne`,
  `\BigBoundaryOnePct`, `\BigBoundaryTwoPct`, taken from
  `large_threshold_output.json`. Long Lean identifiers are typeset with the
  breakable `\lean{...}` command (a `url`-style command); do not use it in
  captions, section titles or math.
- `refs.bib` — bibliography (`plainnat`, numeric, 24 entries, all cited; set
  in `\small`). All entries are primary literature or standard references;
  DOIs are printed by `plainnat`.
- `main.bbl` — generated by BibTeX; arXiv needs it alongside `main.tex`.
- `figures/tradeoff.pdf`, `figures/observation_windows.pdf`,
  `figures/uncertainty.pdf` — exact six-state spectral formula of the
  declared source (rational eigenvectors, five exponentials), produced by
  `make_figures.py`. `figures/large_threshold.pdf`, `figures/headroom_limit.pdf`
  — Laplace-inversion and limit-law numerics from
  `large_threshold_output.json`. Nothing is a simulation.
- `check_paper.py` — exact replay (run with the repository `.venv` Python;
  needs numpy, scipy, mpmath). Recomputes the rational eigenvector
  decompositions and rates for capacities 5–10, evaluates every witness of
  Table 1 and of the tolerance theorem in 40-digit arithmetic against the
  1/100 and 1/20 limits, reproduces the numerical window endpoints,
  `lambda_min`, the undepleted reference, the mass-action grid witness, the
  initial-detection fractions, the loading floor and the 368/72 sampling
  counts, and replays the four directed-rounding enclosures of the
  h >= 1e8 theorem (Appendix D) in Python `decimal` with explicit rounding
  modes, cross-checked with mpmath. Writes `check_paper_output.json`.
  Last run (15 September 2026): 41 checks, ALL CHECKS PASSED.
- `large_threshold.py` — Laplace-transform numerics: fixed-Talbot inversion
  of the holding-time transform (O(h) per evaluation, no h-state matrix),
  validated against matrix exponentials at h = 5 and h = 20 (agreement
  1.5e-12); the limit laws of Section 5 (gamma and product-gamma
  quadratures, Bessel closed form at m = 0); the boundary-miss convergence
  table for h = 5 … 1e6; and the h = 1e8 witnesses and boundaries.
  Two stages: `large_threshold.py conv` (about 5 minutes) and
  `large_threshold.py big` (about 1.5 hours, dominated by the h = 1e8
  boundary searches, each transform evaluation costing about 4 minutes
  at 40 Talbot nodes). Writes/updates `large_threshold_output.json`.
  Note: fixed-Talbot inversion is accurate (about 1e-7) near and above the
  blank boundary but returns noise far below it, where the true probability
  is astronomically small; the bracket search therefore starts from the
  limit-law prediction and never accepts a lower endpoint whose value is not
  strictly inside (1e-4, alpha).
- `make_figures.py` — all five figures.
- `build.ps1` — full build chain (runs `check_paper.py` and
  `make_figures.py`, builds in a scratch directory under `%TEMP%`, copies
  `main.pdf`, `main.bbl`, `main.log` back here and the PDF to the parent
  folder). It does not rerun `large_threshold.py`.

## Compiling (MiKTeX, user scope, not on PATH)

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
..\..\..\.venv\Scripts\python.exe check_paper.py
..\..\..\.venv\Scripts\python.exe make_figures.py
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Build in a fresh scratch directory (as `build.ps1` does) if stale auxiliary
files cause trouble. Do not pipe `pdflatex` into `Select-Object -First N`
in PowerShell: closing the pipe kills pdflatex mid-write and leaves a
truncated `.aux` ("File ended while scanning use of \@writefile").
Alternative single-pass engine (Tectonic bundled with the Codex LaTeX
plugin, under
`E:\CodexData\home\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe`):

```powershell
& "<tectonic.exe>" -X compile --keep-logs --outdir . main.tex
```

Page previews for visual QA: `pdftoppm -r 60 -png main.pdf render/p`
(pdftoppm ships with MiKTeX).
