## Compiling (MiKTeX, user scope, not on PATH)

Build in a fresh scratch directory (in-place MiKTeX builds on this machine
have previously produced spurious end-of-run errors):

```powershell
$env:Path = "$env:LOCALAPPDATA\Programs\MiKTeX\miktex\bin\x64;$env:Path"
pdflatex -interaction=nonstopmode main.tex
bibtex main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

Alternative single-pass engine (Tectonic bundled with the Codex LaTeX plugin):

```powershell
& "$env:USERPROFILE\.codex\.tmp\bundled-marketplaces\openai-bundled\plugins\latex\bin\tectonic.exe" -X compile --keep-logs --outdir . main.tex
```

The build of 2026-09-14 produced 20 pages with zero errors, no undefined

Lean module table (a long identifier in a `p{}` column). Every page was
rendered and inspected.

## Editing notes

- Lean identifiers are typeset with `\lean{...}` (url package,
  `\DeclareUrlCommand`), so they break at underscores and dots. Write
  underscores literally inside `\lean{}`. Never use `\lean{}` inside math
  mode or inside a caption; use `\texttt{}` there.
- The two Lean theorem statements in Section 10 are `verbatim` blocks in
  ASCII notation (`forall`, `exists`, `and`, `not`).
- Species and reactions are indexed from 0, matching the Lean sources.
- The figure legend deliberately carries no theorem numbers; the caption
  does, so renumbering only touches `main.tex`.
- Theorems are numbered by section. The companion question answered by the
  paper is Question 8.1 of the kinetic-order manuscript (checked against its
  compiled PDF).
