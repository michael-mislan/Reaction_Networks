# Formal proofs

Lean sources and supporting evidence for the [reaction-network papers](../README.md).
Each paper's “Proofs and notes” page links its formal declarations, manuscript
sources and any computational companions.

- [Build instructions](BUILD.md)
- [Verification scope and trust assumptions](VERIFICATION.md)
- [Lean proof sources](proofs/)
- [Pinned Lean and Mathlib environment](mathlib4_project/)

The Lean development is organized under `proofs/`.

The `papers/` directories contain manuscript sources, claim maps and per-paper
evidence. The `migration/` directory holds source hashes and saved verification
records used by the checking scripts. It is a technical record of the source
collection, not part of the paper catalogue.
