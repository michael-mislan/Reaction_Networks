# Declaration identity and source pointers

Each paper's claim map has one record for each distinct Lean declaration it
requests for audit. A declaration can be exposed by an aggregate module as well
as the module where it is defined; these are source pointers to one declaration,
not additional mathematical results.

A review consolidated 28 repeated entries in the initial maps. Where entries
were consolidated, the primary link identifies the defining module and
`publication_entry_points` preserves every previous module and historical
receipt pointer. Three definitions were located in dependencies of both original
entry points. No proof, theorem assumption, selected source module or requested
declaration name changed. Existing fresh audits retain the same exact name sets
and the same source/environment fingerprints.

[The consolidation record](claim-exposure-consolidation.json) lists the affected
papers. Earlier dated reviews may mention record counts before consolidation.
The current per-paper maps and generated catalogue give the current counts.
Counts across papers can still include the same shared theorem in more than one
paper; they are never counts of distinct solved mathematical problems.
