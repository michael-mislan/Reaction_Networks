# Citation

Cite the manuscript title, paper number, repository URL and Git commit identifier.
For example:

> *Manuscript title*. P005, Reaction networks.
> Repository URL, commit identifier, accessed date.

Replace these fields with the paper and version used. No DOI or publication venue
is assigned by this repository. For adaptations, retain existing attributions and
identify your changes as required by the [applicable license](RIGHTS.md).
